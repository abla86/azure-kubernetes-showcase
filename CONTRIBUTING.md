# Contributing

Thank you for considering a contribution to Azure Kubernetes Showcase.

This repository is an engineering portfolio project. Contributions should improve the technical quality, reproducibility, documentation, accessibility, testing or security of the showcase.

## Useful contribution areas

- Improve Kubernetes manifests or validation.
- Improve Azure Bicep or Terraform examples.
- Add or strengthen automated tests.
- Improve frontend accessibility and usability.
- Improve observability and diagnostics.
- Improve container hardening.
- Improve CI/CD and developer documentation.
- Fix reproducible bugs or documentation errors.

## Before contributing

1. Check existing Issues and Pull Requests.
2. For larger changes, open an issue first so the scope can be discussed.
3. Keep changes focused and reproducible.
4. Do not add credentials, secrets, personal data or patient-identifiable information.
5. Do not represent local validation as an Azure production deployment.

## Pull requests

Please include:

- What changed
- Why it changed
- How it was tested
- Any infrastructure or security implications

A pull request should pass the repository CI checks before merge.

## Scope

This project is a portfolio showcase, not a production healthcare platform. Contributions must not imply clinical validation, regulatory approval or production deployment unless those claims are independently documented and verified.
