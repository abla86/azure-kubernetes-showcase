# Code of Conduct

## Expected behaviour

Contributors are expected to communicate respectfully, give constructive technical feedback, and focus discussion on the work rather than individuals.

## Unacceptable behaviour

Harassment, discrimination, threats, personal attacks, deliberate disruption, publication of private information, and other inappropriate conduct are not acceptable.

## Reporting

For conduct concerns, use the repository's available GitHub contact or reporting mechanisms rather than publishing sensitive details in a public issue.

## Scope

This code of conduct applies to participation in this repository and its project discussions.
